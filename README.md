### Como Rodar o Projeto
Pré-requisitos
-Java JDK 17 ou superior.

-Maven ou Gradle (dependendo da sua build).

-Git.

Passo a Passo
Clone o repositório:

-Bash
-git clone https://github.com/LeonardoC-Jesus/Your_Movie.git
-cd Your_Movie
-git checkout develop
Compile o projeto:

-Bash
-mvn clean install

Execute a aplicação:

-Bash
-mvn spring-boot:run
(Ou execute a classe principal YourMovieApplication.java diretamente na sua IDE).

### Como Testar
O projeto utiliza JUnit 5 e Mockito para garantir a qualidade do código.

Para rodar todos os testes automatizados, execute:

-Bash
-mvn test
